Login Requirements

1. The user should be able to log in using a registered email address and password.

2. The email address is mandatory.

3. The password is mandatory.

4. The password must contain at least 8 characters.

5. If the user enters incorrect credentials, an appropriate error message should be displayed.

6. After 5 unsuccessful login attempts, the user account should be locked.

7. After successful login, the user should be redirected to the dashboard.
